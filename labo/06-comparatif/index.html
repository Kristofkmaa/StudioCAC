HTML, Astro
ou Next.js ?

La même démo, Libecciu, construite trois fois. Les deux versions framework ajoutent des composants pris tels quels à la communauté : l'accordéon et les listes de shadcn/ui, les compteurs, fondus, bouton et cadre animés de Magic UI, les animations de Motion et les notifications de Sonner.

HTML (actuel)Une page écrite à la main, sans outil de construction. Astro + ReactPage en HTML fixe, React seulement pour les morceaux vivants. Next.js + ReactToute la page est une application React.

Le verdict

La beauté

Égale. Le design est le même ; les composants ajoutent des finitions (chiffres qui montent, fondus, bouton qui brille, cadre animé, notification), mais rien qu'on ne puisse faire en HTML.

La vitesse

Le HTML gagne. Astro reste proche (0,8 s de plus avant de pouvoir réserver). Next.js est nettement plus lourd : deux fois le script d'Astro, trois fois plus de blocage.

L'effort

Brancher un composant de la communauté prend quelques minutes en Astro ou Next.js : on copie son fichier. En HTML, il faut le réécrire à la main.

  • Sur téléphone, les listes déroulantes de shadcn/ui sont moins pratiques que celles du téléphone lui-même (la roue native d'iPhone ou d'Android) : un composant à la mode n'est pas toujours un progrès.
  • Les deux versions framework demandent une étape de construction (npm run build) avant chaque mise en ligne ; le résultat est déposé dans le dépôt et GitHub Pages le sert comme aujourd'hui.
  • Le temps d'affichage de la grande photo n'est pas comparé : la même photo arrive au même moment dans les trois versions, mais l'outil de mesure ne la retient pas dans les deux versions framework.

Pour Saitora

Les sites vitrines restent en HTML : ils sont les plus rapides, et la vitesse sur téléphone compte pour Google et pour les clients pressés.

Astro quand un site a besoin de beaucoup de pièces vivantes prises à la communauté (un configurateur, une réservation riche, des animations) : le surcoût est faible et le gain de temps réel.

Next.js seulement pour de vraies applications : espace client, boutique sur mesure, comptes.
