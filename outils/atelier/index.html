02

Le genre

Il décide de tout le reste : la grille, les tailles, le ton. Les aperçus portent le nom de ton projet.

03

La composition

Ne choisis que ce qui compte pour toi. Le reste est tiré au sort dans la session, loin de ce que les autres sites ont déjà. Le chiffre dit combien de sites ont déjà cette option ; en pointillé, ce qui va moins bien avec le genre choisi.

04

Les animations

Ta banque de 44 mouvements. Six à dix suffisent pour un site : au-delà, ça fatigue. « Voir » la joue en vrai.
