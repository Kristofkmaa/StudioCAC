03

Le genre

Il décide de tout le reste : la grille, les tailles, le ton. Les aperçus portent le nom de ton projet.

04

La composition

Ne choisis que ce qui compte pour toi. Le reste est tiré au sort dans la session. En pointillé, ce qui va moins bien avec le genre choisi.

05

Les animations

Ta banque de 100 mouvements : 50 basiques, 50 premium, dont quatre séries faites pour un métier. Six à dix suffisent pour un site : au-delà, ça fatigue. « Voir » la joue en vrai.

06

Tes consignes

Ce que tu veux absolument, ce que tu ne veux pas, ce que le client a demandé.

Mes règles de toujours

Elles partent dans chaque prompt, pour ne plus avoir à les répéter. Elles restent quand tu effaces un projet.

07

Le prompt

Copie-le et colle-le dans une nouvelle session Claude Code sur le dépôt StudioCAC. Tu peux le retoucher ici avant de copier.

Le cadre descend tout seul jusqu’à l’animation : fais défiler dedans pour la voir jouer. Si le cadre reste vide, ouvre ta banque d’animations.
